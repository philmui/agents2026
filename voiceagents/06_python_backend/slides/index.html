Concept · the whole point

Anything the browser downloads is readable

Open View Source or the Network tab and every string is visible.
There is no "hide from the user" in a browser.
LEAKED A sk- key on the page is a leaked secret, full stop.
CAUTION A frontend env var is NOT safe. Putting the key in a Next.js NEXT_PUBLIC_... variable still ships it to the browser. The only safe place for sk- is a server the user cannot read.

Concept · the disposable token

What an ephemeral ek_ token is

1Short-lived
Expires in about a minute. A copy stops working almost at once.
2Scoped
Born from a session template: it can only start the one session you configured.

Analogy: the real key is your credit card. The ek_ token is a $5 gift card that self-destructs in a minute. Hand out gift cards freely, never your credit card.

CAUTION Because they expire fast, the browser fetches a fresh one right before connecting. Never cache an ek_ token; it will be dead.

Tool · FastAPI in 60 seconds

Attach routes to an app object

from fastapi import FastAPI

app = FastAPI()            # the application

@app.get("/health")       # GET /health -> health()
async def health():
    return {"status": "ok"}   # dict -> JSON
uv run uvicorn src.main:app \
    --reload --port 8000
@app.get(...) is a decorator: it registers the function as the handler for that URL.
uvicorn is the server that listens on a port and calls into app. --reload restarts on edits.
Free interactive docs at /docs let you click to try each route.

Concept · Cross-Origin Resource Sharing

CORS lets :3000 call :8000

Browsers enforce the same-origin policy: scheme + host + port must match.
Frontend :3000 ≠ backend :8000, so the call is blocked by default.
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:3000",
        "http://127.0.0.1:3000",
    ],
    allow_methods=["*"],   # incl. OPTIONS
    allow_headers=["*"],
)
CAUTION This is local dev only. In production set allow_origins to your real site URL. Never pair allow_origins=["*"] with allow_credentials=True: browsers reject it, and a wildcard lets any site call your minter.

The call that makes it work

POST client_secrets with the real key

CLIENT_SECRETS_URL = (
  "https://api.openai.com/v1/realtime/client_secrets")

headers = {
  "Authorization": f"Bearer {OPENAI_API_KEY}",
  "Content-Type": "application/json",
}
payload = {"session": {
  "type": "realtime",
  "model": "gpt-realtime-2.1",
  "audio": {"output": {"voice": "marin"}},
}}
The session block is the scope: the ek_ token inherits exactly this and nothing more.
Sent server-to-server over HTTPS. The real key never touches the browser.
voice: "marin" is locked for the session and cannot change later.

Reading the reply · async httpx

The token is at data.value

async with httpx.AsyncClient(timeout=10.0) as client:
    r = await client.post(
        CLIENT_SECRETS_URL,
        headers=headers, json=payload,
    )

data = r.json()
ek = data.get("value")   # "ek_..."  <-- the token
# return ONLY ek (+ model) to the browser
async lets the handler pause on the network without freezing the server.
async with cleans up the connection even on error; json= sets the body.
CAUTION The field is value, not client_secret or key. And at GA there is no OpenAI-Beta: realtime=v1 header. Do not send it.

Robustness · fail clearly, never leak

Guard each step with a clean error

500 our server is misconfigured (no key loaded)
502 a server we depend on failed (OpenAI down, bad key, rate limit)
if not OPENAI_API_KEY:
    raise HTTPException(500, "OPENAI_API_KEY not set")

if r.status_code != 200:
    raise HTTPException(502, f"OpenAI: {r.text}")
CAUTION Never echo the real key into an error string. Build messages from OpenAI's reply, not your request. An Authorization header interpolated into a returned string is a leak into the Network tab.

The end-to-end handshake

Browser → backend → OpenAI → ek_ → browser

The real key never travels to the browser; the audio path (module 07) is browser ↔ OpenAI directly, authorized by the disposable ek_.

The one idea to remember

trade the sk- master key for a disposable ek_ token  ·  hand out only the ek_
1The real key stays on a server the user cannot read. That is the entire reason this module exists.
2The browser only ever holds a short-lived, scoped token. Losing it is cheap; the master key is safe.
