# Original classroom corpus

All people, records, measurements, and interfaces are fictional. Generated by `tools/build_corpus.py`; no external media or personal data.

The three charts store their measurements in pixels. The raw memos contain no chart measurements. `reference_parses.json` is a hand-authored ingestion fixture, not model output. `answer_key.json` is evaluation-only ground truth. Keeping those separate prevents evaluating a model against its own prediction.

`solar_lab_report.pdf` has native text on page 1 and a raster image on page 2. `solar_lab_review.avi` is a silent, 12-second MJPG video; `transcript.json` is a hand-authored companion transcript, not an automatic transcription.
