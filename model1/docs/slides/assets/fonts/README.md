# Embedded fonts

The deck embeds Latin WOFF2 subsets of **Bricolage Grotesque** and **Source Sans 3**, downloaded from Google Fonts on 2026-10-03. Both are distributed under the SIL Open Font License 1.1.

- [Bricolage Grotesque license](bricolagegrotesque-OFL.txt), from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque).
- [Source Sans 3 license](sourcesans3-OFL.txt), from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/sourcesans3).

The corresponding font binaries are stored one directory above this guide as `bricolage-latin.woff2` and `source-sans-latin.woff2`. The slide builder embeds them as data URLs, so presentation use does not contact the font service.
