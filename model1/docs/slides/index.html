04 · Meet Jev

Noul asks a yes-or-no question

Noul estimates whether one statement is true. A value near 1 favors yes, near 0 favors no, and near 0.5 leaves the answer uncertain.

Noul is P(yes) for one question; it does not include a separate confidence field.

Confidence differs from probability

For three Choice options, an even split gives each one ⅓. Jev’s confidence rescales the top probability relative to that baseline; it is a different number from P(top option).

Choice confidence depends on how many options you offer and still needs validation.
