# Root visual assets

These SVG files illustrate the ideas shared by the two learning paths in this repository. They are plain, editable vector graphics with embedded titles and descriptions for screen-reader users.

- `research-cycle.svg`: the evidence-centered team research cycle.
- `agentic-rag-system.svg`: a RAG system and the evaluation feedback loop.
- `voice-agent-architecture.svg`: a secure browser, backend, and Realtime API architecture.

The diagrams use text labels, line styles, and shapes in addition to color. They can be reused in Markdown, slides, or documentation without rasterizing them.
